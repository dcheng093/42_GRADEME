Assignment name  : py_string_sculptor
Expected files   : py_string_sculptor.py
--------------------------------------------------------------------------------

Напишите функцию, которая преобразует строку, чередуя регистр только для букв.

Небуквенные символы остаются неизменными и НЕ учитываются при чередовании.
Первая буква должна быть строчной (маленькой), вторая - прописной (большой) и т. д.

def string_sculptor(text: str) -> str:

Примеры:

string_sculptor("hello")        → "hElLo"
string_sculptor("Hello World")  → "hElLo WoRlD"
string_sculptor("   hello   ")  → "   hElLo   "
string_sculptor("abc123def")    → "aBc123DeF"
string_sculptor("Python3.9!")   → "pYtHoN3.9!"
string_sculptor("")             → ""
