Assignment name  : py_constellation_mapper
Expected files   : py_constellation_mapper.py
--------------------------------------------------------------------------------

Schreibe eine Funktion, die eine Sternkonstellation auf ein Raster abbildet und das Ergebnis als Liste von Zeichenketten zurückgibt.

Die Funktion soll:
- Eine Liste von Sternkoordinaten als Tupel (Zeile, Spalte) und die Rastergröße als Ganzzahl entgegennehmen
- Eine Liste von Zeichenketten zurückgeben, die das Raster darstellen
- Sterne werden durch '*' und leere Felder durch '.' dargestellt
- Rasterkoordinaten beginnen bei (0, 0) oben links
- Koordinaten außerhalb der Rastergrenzen ignorieren
- Doppelte Koordinaten behandeln (jeder Stern wird nur einmal platziert)

def constellation_mapper(stars: list[tuple[int, int]], dim: int) -> list[str]:

Beispiele:

constellation_mapper([(0, 0), (1, 1), (2, 2)], 3)             → ['*..', '.*.', '..*']
constellation_mapper([(1, 1), (0, 1), (2, 1), (1, 0), (1, 2)], 3)
                                                              → ['.*.', '***', '.*.']
constellation_mapper([], 2)                                   → ['..', '..']
constellation_mapper([(0, 0), (0, 0), (1, 1)], 2)             → ['*.', '.*']
constellation_mapper([(0, 0), (5, 5)], 3)                     → ['*..', '...', '...']
constellation_mapper([(1, 0), (1, 1), (1, 2)], 3)             → ['...', '***', '...']
