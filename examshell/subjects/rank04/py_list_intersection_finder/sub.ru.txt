--------------------------------------------------------------------------------

Напишите функцию, которая находит пересечение нескольких отсортированных списков. Возвращайте новый список, содержащий элементы, которые присутствуют во ВСЕХ входных списках, в отсортированном порядке.

Функция должна:
- Возвращать элементы, присутствующие во ВСЕХ списках
- Результат должен быть отсортирован по возрастанию
- Удалять дубликаты из результата
- Корректно обрабатывать пустой ввод или пустые списки
- Если какой-либо список пуст, пересечение считается пустым

def list_intersection_finder(lists: list[list[int]]) -> list[int]:

Примеры:

list_intersection_finder([[1, 2, 3], [2, 3, 4], [2, 3, 5]])   → [2, 3]
list_intersection_finder([[1, 2, 3, 4], [2, 4, 6, 8], [4, 8, 12]])
                                                              → [4]
list_intersection_finder([[1, 1, 2, 3], [1, 2, 2, 3], [1, 2, 3, 3]])
                                                              → [1, 2, 3]
list_intersection_finder([[1, 2, 3], [4, 5, 6]])              → []
list_intersection_finder([])                                  → []
list_intersection_finder([[1, 2, 3], []])                     → []
