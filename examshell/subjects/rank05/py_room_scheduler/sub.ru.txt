Assignment name  : py_room_scheduler
Expected files   : py_room_scheduler.py
--------------------------------------------------------------------------------

Напишите функцию, которая определяет минимальное количество переговорных комнат для расписания встреч без наложений и распределяет встречи по комнатам.

Каждая встреча представлена списком `[start_time, end_time]`.

Функция должна:
- Возвращать словарь с `"total_rooms"` (количество комнат) и `"schedule"` (список встреч для каждой комнаты).
- Возвращать `{"total_rooms": 0, "schedule": []}`, если список пуст.

def py_room_scheduler(meetings: list[list[int]]) -> dict[str, Any]:

Примеры:

py_room_scheduler([[0, 30], [5, 10], [15, 20]])  → {"total_rooms": 2, "schedule": [[[0, 30]], [[5, 10], [15, 20]]]}
py_room_scheduler([])                            → {"total_rooms": 0, "schedule": []}
