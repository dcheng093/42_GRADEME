Assignment name  : bridge_finder

--------------------------------------------------------------------------------

Écrivez une fonction qui trouve tous les ponts (isthmes) dans un graphe non orienté. Un pont est une arête dont la suppression augmente le nombre de composantes connexes du graphe.

La fonction doit :
- Prendre un graphe non orienté sous forme de liste d'adjacence ;
- Retourner tous les ponts sous forme d'une liste de tuples (u, v) où u < v ;
- Retourner les résultats triés par premier élément, puis par second élément ;
- Gérer les graphes vides (retourner une liste vide) ;
- Gérer les graphes sans ponts (retourner une liste vide).

def bridge_finder(graph: dict[int, list[int]]) -> list[tuple[int, int]]:

Exemples:

bridge_finder({0: [1, 2], 1: [0, 2], 2: [0, 1]})              → []
bridge_finder({0: [1], 1: [0, 2], 2: [1]})                    → [(0, 1), (1, 2)]
bridge_finder({0: [1, 2], 1: [0, 2, 3], 2: [0, 1], 3: [1]})   → [(1, 3)]
bridge_finder({})                                             → []
bridge_finder({0: [1], 1: [0]})                               → [(0, 1)]
bridge_finder({0: [1, 2], 1: [0, 2, 3, 4], 2: [0, 1], 3: [1, 4], 4: [1, 3]})
                                                              → []
