Assignment name  : bridge_finder
Expected files   : bridge_finder.py
--------------------------------------------------------------------------------

Scrivi una funzione che trovi tutti i ponti in un grafo non orientato. Un ponte è un arco la cui rimozione aumenta il numero di componenti connesse nel grafo.

La funzione deve:
- Ricevere un grafo non orientato come lista di adiacenza;
- Restituire tutti i ponti come lista di tuple (u, v) dove u < v;
- Restituire i risultati ordinati per il primo elemento e poi per il secondo elemento;
- Gestire i grafi vuoti (restituire una lista vuota);
- Gestire i grafi senza ponti (restituire una lista vuota).

def bridge_finder(graph: dict[int, list[int]]) -> list[tuple[int, int]]:

Esempi:

bridge_finder({0: [1, 2], 1: [0, 2], 2: [0, 1]})              → []
bridge_finder({0: [1], 1: [0, 2], 2: [1]})                    → [(0, 1), (1, 2)]
bridge_finder({0: [1, 2], 1: [0, 2, 3], 2: [0, 1], 3: [1]})   → [(1, 3)]
bridge_finder({})                                             → []
bridge_finder({0: [1], 1: [0]})                               → [(0, 1)]
bridge_finder({0: [1, 2], 1: [0, 2, 3, 4], 2: [0, 1], 3: [1, 4], 4: [1, 3]})
                                                              → []
