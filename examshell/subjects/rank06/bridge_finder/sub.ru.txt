Assignment name  : bridge_finder
Expected files   : bridge_finder.py
--------------------------------------------------------------------------------

Напишите функцию, которая находит все мосты в неориентированном графе. Мост - это ребро, удаление которого увеличивает количество компонент связности в графе.

Функция должна:
- Принимать неориентированный граф в виде списка смежности;
- Возвращать все мосты в виде списка кортежей (u, v), где u < v;
- Возвращать результаты, отсортированные сначала по первому элементу, затем по второму элементу;
- Корректно обрабатывать пустые графы (возвращать пустой список);
- Корректно обрабатывать графы без мостов (возвращать пустой список).

def bridge_finder(graph: dict[int, list[int]]) -> list[tuple[int, int]]:

Примеры:

bridge_finder({0: [1, 2], 1: [0, 2], 2: [0, 1]})              → []
bridge_finder({0: [1], 1: [0, 2], 2: [1]})                    → [(0, 1), (1, 2)]
bridge_finder({0: [1, 2], 1: [0, 2, 3], 2: [0, 1], 3: [1]})   → [(1, 3)]
bridge_finder({})                                             → []
bridge_finder({0: [1], 1: [0]})                               → [(0, 1)]
bridge_finder({0: [1, 2], 1: [0, 2, 3, 4], 2: [0, 1], 3: [1, 4], 4: [1, 3]})
                                                              → []
