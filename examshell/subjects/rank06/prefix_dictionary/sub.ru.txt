Реализуйте класс с именем `PrefixDictionary`, представляющий префиксное дерево (Trie).

Класс должен содержать следующие методы:

1. `__init__(self)`:
Инициализирует пустое префиксное дерево.

2. `insert(self, word: str) -> None`:
Вставляет строку `word` в префиксное дерево.

3. `search(self, word: str) -> bool`:
Возвращает `True`, если точная строка `word` присутствует в префиксном дереве, и `False` в противном случае.

4. `starts_with(self, prefix: str) -> bool`:
Возвращает `True`, если существует хотя бы одно ранее добавленное слово, начинающееся с указанного префикса `prefix`, и `False` в противном случае.

Все входные строки состоят только из строчных букв латинского алфавита (`'a'` - `'z'`).
