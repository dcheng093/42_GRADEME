Un árbol es un grafo no dirigido conexo y sin ciclos.

Se te proporciona un grafo no dirigido que comenzó como un árbol con `n` nodos etiquetados del `1` al `n`, pero al que se le añadió una arista adicional. Como resultado, el grafo contiene exactamente un ciclo.

El grafo se describe mediante una lista `edges` de longitud `n`, donde `edges[i] = [u, v]` representa una arista entre los vértices `u` y `v`.

Escribe una función `redundant_link` que devuelva una arista que pueda ser eliminada para que el grafo vuelva a ser un árbol de `n` nodos.
Si existen varias opciones posibles, devuelve la arista que aparezca en última posición en la lista `edges`.

def redundant_link(edges: list[list[int]]) -> list[int]:

Ejemplos:

redundant_link([[1, 2], [1, 3], [2, 3]])                  → [2, 3]
redundant_link([[1, 2], [2, 3], [3, 4], [1, 4], [1, 5]])  → [1, 4]
redundant_link([[1, 4], [3, 4], [1, 3], [1, 2], [4, 5]])  → [1, 3]
