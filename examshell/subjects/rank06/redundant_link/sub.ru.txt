Дерево - это неориентированный связный граф без циклов.

Вам дан неориентированный граф, который изначально являлся деревом с `n` вершинами (пронумерованными от `1` до `n`), но затем к нему было добавлено ровно одно ребро, образовавшее один цикл.

Граф задан списком `edges` длины `n`, где каждый элемент `edges[i] = [u, v]` обозначает ребро между вершинами `u` и `v`.

Напишите функцию `redundant_link`, которая находит и возвращает ребро, удаление которого возвращает графу структуру дерева из `n` вершин.
Если удалить можно несколько разных ребер, верните то, которое встречается в списке `edges` последним.

def redundant_link(edges: list[list[int]]) -> list[int]:

Примеры:

redundant_link([[1, 2], [1, 3], [2, 3]])                  → [2, 3]
redundant_link([[1, 2], [2, 3], [3, 4], [1, 4], [1, 5]])  → [1, 4]
redundant_link([[1, 4], [3, 4], [1, 3], [1, 2], [4, 5]])  → [1, 3]
