Assignment name  : task_order
Expected files   : task_order.py
Forbidden functions : graphlib.TopologicalSorter
--------------------------------------------------------------------------------

Es gibt `n` Aufgaben, nummeriert von `0` bis `n - 1`. Gegeben sind eine Ganzzahl `n` und eine Liste von Abhängigkeitspaaren `prereqs`, wobei jedes Paar `[a, b]` bedeutet, dass Aufgabe `b` abgeschlossen sein muss, bevor Aufgabe `a` begonnen werden kann.

Schreibe eine Funktion `task_order`, die eine gültige Reihenfolge zurückgibt, in der alle Aufgaben ausgeführt werden können.

Anforderungen:
- Wenn mehrere Aufgaben gleichzeitig ausgeführt werden können (keine offenen Voraussetzungen mehr haben), wähle stets die Aufgabe mit dem kleinsten Index (lexikographische Reihenfolge).
- Wenn es aufgrund einer zyklischen Abhängigkeit unmöglich ist, alle Aufgaben abzuschließen, gib eine leere Liste `[]` zurück.
- Die Verwendung von `graphlib.TopologicalSorter` ist nicht gestattet.

def task_order(n: int, prereqs: list[list[int]]) -> list[int]:

Beispiele:

task_order(2, [[1, 0]])                          → [0, 1]
task_order(4, [[1, 0], [2, 0], [3, 1], [3, 2]])  → [0, 1, 2, 3]
task_order(2, [[0, 1], [1, 0]])                  → []
task_order(3, [])                                → [0, 1, 2]
