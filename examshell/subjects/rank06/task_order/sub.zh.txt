有 `n` 个任务，编号从 `0` 到 `n - 1`。给定一个整数 `n` 和依赖对列表 `prereqs`，其中每个对 `[a, b]` 表示在开始任务 `a` 之前必须先完成任务 `b`。

编写一个函数 `task_order`，返回一个能够完成所有任务的有效执行顺序。

要求：
- 当有多个任务没有前置依赖且可以同时选择时，始终选择编号最小的任务（字典序优先）。
- 如果由于存在循环依赖（环）而无法完成所有任务，返回空列表 `[]`。
- 禁止使用 `graphlib.TopologicalSorter`。

def task_order(n: int, prereqs: list[list[int]]) -> list[int]:

示例:

task_order(2, [[1, 0]])                          → [0, 1]
task_order(4, [[1, 0], [2, 0], [3, 1], [3, 2]])  → [0, 1, 2, 3]
task_order(2, [[0, 1], [1, 0]])                  → []
task_order(3, [])                                → [0, 1, 2]
