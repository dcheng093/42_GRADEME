Assignment name  : sorted
Expected files   : sorted.py
--------------------------------------------------------------------------------

Write a function:

def sort_people(people: list[tuple[str, int]]) -> list[tuple[str, int]]:

that takes a list of (name, age) tuples and returns a new list sorted by age
in ascending order. People with the same age are sorted by name in
alphabetical order (normal string comparison, so uppercase letters come
before lowercase ones).

The original list must not be modified.

Hint: sorted() accepts a key= argument. A key can return a tuple to sort by
several criteria at once.

Examples:

sort_people([("Zoe", 30), ("Adam", 25)])
→ [("Adam", 25), ("Zoe", 30)]

sort_people([("Bob", 40), ("Alice", 40), ("Eve", 19)])
→ [("Eve", 19), ("Alice", 40), ("Bob", 40)]

sort_people([])
→ []
