Assignment name  : py_package_dependency_resolver
Expected files   : py_package_dependency_resolver.py
Forbidden functions : graphlib.TopologicalSorter
--------------------------------------------------------------------------------

Напишите функцию, которая определяет валидный порядок установки пакетов путем разрешения зависимостей. Используйте топологическую сортировку, чтобы зависимости устанавливались перед пакетами, которые их требуют.

Функция должна:
- Принимать словарь, где ключи - названия пакетов, а значения - списки их зависимостей.
- Возвращать пакеты в порядке установки (зависимости первыми).
- Возвращать пустой список ([]), если валидного порядка не существует (например, при циклических или авто-зависимостях).
- Корректно обрабатывать пустой ввод и изолированные цепочки зависимостей.
- Игнорировать ссылки на пакеты, которых нет среди ключей входного словаря.
- Гарантировать, что пакет не может быть установлен, пока не установлены все его зависимости.

Детали алгоритма и крайние случаи:
- Топологическая сортировка: Используйте алгоритм топологической сортировки (например, алгоритм Кана).
- Приоритет зависимостей: Сначала обрабатывайте пакеты, у которых больше не осталось неразрешенных зависимостей.
- Детерминированный вывод: Если одновременно могут быть обработаны несколько пакетов (есть выбор), обрабатывайте их в алфавитном порядке для обеспечения детерминированности.
- Пустой ввод: Возвращайте пустой список.
- Несколько независимых цепочек: Обрабатывайте все цепочки, соблюдая алфавитный порядок.
- Отсутствующие зависимости: Игнорируйте отсутствующие пакеты (относитесь к ним так, будто их нет в списке требований).

def package_dependency_resolver(packages: dict[str, list[str]]) -> list[str]:

Примеры:

package_dependency_resolver({"app": ["database"], "database": ["driver"], "driver": []})
                                                              → ["driver", "database", "app"]
package_dependency_resolver({"A": [], "B": ["A"], "C": ["A", "B"]})
                                                              → ["A", "B", "C"]
package_dependency_resolver({})                               → []
package_dependency_resolver({"X": ["Y"], "Y": ["X"]})         → []
package_dependency_resolver({"web": [], "api": [], "frontend": ["web"], "backend": ["api"]})
                                                              → ["api", "web", "backend", "frontend"]
