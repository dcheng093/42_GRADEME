Дан список целых чисел nums и целое число k. Представьте «окно» размера k, скользящее слева направо по одной позиции за раз.

Для каждого положения окна найдите максимальное значение внутри него.
Верните список всех этих максимальных значений в порядке появления окон.

Ограничения:
- 1 <= k <= len(nums) в обычных случаях.
- Если список nums пуст или k <= 0, верните [].
- Количество окон (и максимумов) равно: len(nums) - k + 1.

Примеры:

sliding_window_maximum([1, 3, -1, -3, 5, 3, 6, 7], 3)  → [3, 3, 5, 5, 6, 7]
sliding_window_maximum([1, 2, 3, 4, 5], 2)             → [2, 3, 4, 5]
sliding_window_maximum([5, 4, 3, 2, 1], 1)             → [5, 4, 3, 2, 1]

sliding_window_maximum([], 2)                          → []
