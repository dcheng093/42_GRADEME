--------------------------------------------------------------------------------

Implémente une classe nommée `PrefixDictionary` représentant un arbre préfixe (Trie).

La classe doit fournir les méthodes suivantes :

1. `__init__(self)` :
Initialise un dictionnaire de préfixes vide.

2. `insert(self, word: str) -> None` :
Insère la chaîne `word` dans le dictionnaire de préfixes.

3. `search(self, word: str) -> bool` :
Renvoie `True` si la chaîne exacte `word` a été insérée dans le dictionnaire, et `False` sinon.

4. `starts_with(self, prefix: str) -> bool` :
Renvoie `True` s'il existe une chaîne précédemment insérée qui commence par le `prefix` donné, et `False` sinon.

Toutes les entrées sont composées uniquement de lettres minuscules (`'a'` - `'z'`).
