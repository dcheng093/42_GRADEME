Ein Baum ist ein ungerichteter zusammenhängender Graph ohne Zyklen.

Gegeben ist ein ungerichteter Graph, der als Baum mit `n` Knoten (beschriftet von `1` bis `n`) begann, zu dem jedoch eine zusätzliche Kante hinzugefügt wurde. Dadurch enthält der Graph genau einen Zyklus.

Der Graph wird durch eine Liste `edges` der Länge `n` dargestellt, wobei `edges[i] = [u, v]` eine Kante zwischen den Knoten `u` und `v` repräsentiert.

Schreibe eine Funktion `redundant_link`, die eine Kante zurückgibt, deren Entfernung den Graphen wieder in einen Baum mit `n` Knoten verwandelt.
Gibt es mehrere Möglichkeiten, gib diejenige Kante zurück, die in der übergebenen Liste `edges` als letzte vorkommt.

def redundant_link(edges: list[list[int]]) -> list[int]:

Beispiele:

redundant_link([[1, 2], [1, 3], [2, 3]])                  → [2, 3]
redundant_link([[1, 2], [2, 3], [3, 4], [1, 4], [1, 5]])  → [1, 4]
redundant_link([[1, 4], [3, 4], [1, 3], [1, 2], [4, 5]])  → [1, 3]
