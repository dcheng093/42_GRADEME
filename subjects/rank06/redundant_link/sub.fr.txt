Un arbre est un graphe non orienté connexe sans cycle.

On vous donne un graphe non orienté qui était initialement un arbre à `n` nœuds étiquetés de `1` à `n`, auquel une arête supplémentaire a été ajoutée. Le graphe contient donc exactement un cycle.

Le graphe est représenté par une liste `edges` de longueur `n`, où chaque élément `edges[i] = [u, v]` représente une arête entre les sommets `u` et `v`.

Écris une fonction `redundant_link` qui renvoie une arête pouvant être retirée pour que le graphe redevienne un arbre de `n` nœuds.
S'il existe plusieurs réponses possibles, renvoie l'arête qui apparaît en dernier dans la liste `edges`.

def redundant_link(edges: list[list[int]]) -> list[int]:

Exemples:

redundant_link([[1, 2], [1, 3], [2, 3]])                  → [2, 3]
redundant_link([[1, 2], [2, 3], [3, 4], [1, 4], [1, 5]])  → [1, 4]
redundant_link([[1, 4], [3, 4], [1, 3], [1, 2], [4, 5]])  → [1, 3]
