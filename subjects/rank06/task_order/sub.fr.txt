Assignment name  : task_order
Expected files   : task_order.py
Forbidden functions : graphlib.TopologicalSorter
--------------------------------------------------------------------------------

Il y a `n` tâches numérotées de `0` à `n - 1`. On vous donne un entier `n` et une liste de paires de dépendances `prereqs`, où chaque paire `[a, b]` indique que la tâche `b` doit être terminée avant de pouvoir commencer la tâche `a`.

Écris une fonction `task_order` qui renvoie un ordre valide permettant d'accomplir toutes les tâches.

Exigences :
- Lorsque plusieurs tâches n'ont plus de prérequis et peuvent être choisies en même temps, choisis toujours celle ayant le plus petit indice (ordre lexicographique).
- S'il est impossible de terminer toutes les tâches en raison d'une dépendance circulaire (cycle), renvoie une liste vide `[]`.
- L'utilisation de `graphlib.TopologicalSorter` est interdite.

def task_order(n: int, prereqs: list[list[int]]) -> list[int]:

Exemples:

task_order(2, [[1, 0]])                          → [0, 1]
task_order(4, [[1, 0], [2, 0], [3, 1], [3, 2]])  → [0, 1, 2, 3]
task_order(2, [[0, 1], [1, 0]])                  → []
task_order(3, [])                                → [0, 1, 2]
