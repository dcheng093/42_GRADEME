Assignment name  : task_order
Expected files   : task_order.py
Forbidden functions : graphlib.TopologicalSorter
--------------------------------------------------------------------------------

Имеется `n` задач, пронумерованных от `0` до `n - 1`. Вам дано число `n` и список зависимостей `prereqs`, где пара `[a, b]` означает, что задача `b` должна быть выполнена перед началом задачи `a`.

Напишите функцию `task_order`, которая возвращает допустимый порядок выполнения всех задач.

Требования:
- Если одновременно доступны для выполнения несколько задач (у них нет невыполненных зависимостей), всегда выбирайте задачу с наименьшим номером (лексикографический порядок).
- Если невозможно выполнить все задачи из-за наличия циклической зависимости, верните пустой список `[]`.
- Запрещено использовать `graphlib.TopologicalSorter`.

def task_order(n: int, prereqs: list[list[int]]) -> list[int]:

Примеры:

task_order(2, [[1, 0]])                          → [0, 1]
task_order(4, [[1, 0], [2, 0], [3, 1], [3, 2]])  → [0, 1, 2, 3]
task_order(2, [[0, 1], [1, 0]])                  → []
task_order(3, [])                                → [0, 1, 2]
